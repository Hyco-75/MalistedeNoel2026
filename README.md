# Ma liste de Noël

Site statique (HTML/CSS/JS), sans dépendance.

## Mettre en ligne avec GitHub Pages
1. Crée un dépôt GitHub et envoie tous ces fichiers à la racine.
2. Settings → Pages → Source : branche `main`, dossier `/ (root)` → Save.
3. Le site apparaît sur `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`.

## Ajouter un souhait
Ouvre `data.js` et copie un bloc. `url: null` = idée libre. Pour une photo, mets l’image dans `images/` et renseigne `image: "images/ma-photo.jpg"`.
